# Astrum Craftfly

Landing page institucional responsiva desenvolvida com **React + Vite**, criada para apresentar a empresa **Astrum Craftfly**, voltada a marketing e desenvolvimento de software.  
O projeto tem foco em presença digital, portfólio e demonstração de habilidades em desenvolvimento front-end moderno.

## 🚀 Demo

Acesse a aplicação publicada em produção:  
🔗 https://astrum-craftfly.vercel.app/

---

## 🛠️ Tecnologias Utilizadas

- React
- Vite
- Tailwind CSS
- JavaScript (ES6+)
---

## ⚙️ Como Executar o Projeto Localmente

### Pré-requisitos
- Node.js (versão 18 ou superior)
- npm ou yarn

### Passo a passo

1. Clone o repositório:
```bash
git clone https://github.com/CrisleyWolgien/astrum-craftfly.git

    Acesse a pasta do projeto:

cd astrum-craftfly

    Instale as dependências:

npm install

    Inicie o servidor de desenvolvimento:

npm run dev
```

O projeto estará disponível em:

http://localhost:5173
